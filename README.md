## ✨ Features

- 👤 **Created & Developed by Sandeep Patra** ([@devloper_sandeep](https://instagram.com/devloper_sandeep)).
- 🖐️ **3D Hand Sign Animation**: Large Gojo-inspired hand sign constructed with smooth ASCII rendering.
- 🌌 **Domain Expansion Sequence**: Pulsing text effects and "Infinite Void" animations with dynamic `lolcat`-style rainbow gradients.
- 📶 **Auto Bluetooth Power-On**: Automatically attempts to unblock and initialize the local Bluetooth interface (`hci0`).
- 🔍 **Automated Device Discovery**: Scans local Bluetooth signals using `hcitool scan` and automatically locks onto targets like **jaym**.
- ⚡ **Multi-threaded Execution**: Runs target sync in a background thread to prevent UI freezing without affecting local Bluetooth audio/music playback.
- 🎨 **24-Bit RGB Rendering**: Truecolor mathematical sine wave gradient generator built natively into Python without external CLI dependencies.

---

## 🎁 What You Get

- **Complete Terminal UI Suite**: Full animated Jujutsu Kaisen Domain Expansion experience inside Linux and Termux CLI.
- **Automated Hardware Initialization**: Script auto-detects `hci0`, runs `rfkill unblock bluetooth`, and manages adapter states effortlessly.
- **Target Locking Engine**: Quick device search with targeted stream synchronization.
- **Ultra-Speed Data Stream Engine**: Real-time non-blocking packet counter display running on daemon threads.
- **Modular Installer (`install.sh`)**: Single-command script for auto-installing system packages (`bluez`, `python3`, `tsu`, `rfkill`).

## ⚡ Quick Start

### 1. Install
Clone the repository to your environment:
```bash
git clone https://github.com/devloper-sandeep/Bluetooth-Jaymer.git
cd Bluetooth-Jaymer
bash install.sh
```

### 2. Start FCC
Launch the Bluetooth Jaymer console with high-privilege access:

**For Termux (Android):**
```bash
tsu
python bluetooth_jaymer.py
```

**For Standard Linux (Ubuntu / Debian / Kali):**
```bash
sudo python3 bluetooth_jaymer.py
```
